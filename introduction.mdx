# Introduction

**AdCue** helps you inspect and operate Google Ads from AI clients through a safety-first MCP tool surface.
Google Search is the primary workflow, and the recommended first session stays read-only.

## Start here

The launch path is:

1. [Create an AdCue account](/create-account).
2. [Connect Google Ads](/connect/google-ads) and choose a client ad account as primary.
3. Confirm your private-beta [ChatGPT entitlement](/ai-clients/chatgpt) through the invitation or connector listing provided for your account.
4. Authorize the connector with AdCue OAuth.
5. Run `get_connections_status` as your first read.

<Note>
ChatGPT access is not automatically enabled for every account.
AdCue OAuth in ChatGPT and Google Ads OAuth in Connections are separate authorizations.
The official ChatGPT path does not require you to paste an API key.
</Note>

## What AdCue is for

| Goal | How AdCue helps |
| --- | --- |
| Understand account state | Read connections, client accounts, campaigns, structure, performance, and conversion tracking |
| Find waste | Analyze search terms and wasted spend before proposing a change |
| Build Search campaigns | Research, create, and verify Google Search campaigns that land paused |
| Operate from AI clients | Use the AdCue MCP surface from entitled ChatGPT accounts and other clients covered by in-app Setup |

See [Capabilities](/knowledge/capabilities) for the supported boundary and advanced-tool rules.

## Product boundary

AdCue's live advertising surface is **Google Ads only**.
Search is the primary end-to-end path.
Advanced Performance Max, YouTube, and Demand Gen tools remain visible in the catalog, but the live `google_ads` `list_tools` response is the runtime source of truth.

AdCue does not document other advertising platforms, a public advertising REST API, or server-side monitoring as shipped capabilities.
