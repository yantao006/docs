# Introduction

**AdCue** helps you audit, optimize, and operate **Google Ads** through:

- A product shell at [adcue.app/app](https://adcue.app/app)
- An MCP endpoint at [mcp.adcue.app/mcp](https://mcp.adcue.app/mcp) for AI clients (Claude, Cursor, ChatGPT, and other MCP-compatible tools)

Use natural language or structured tool calls to list campaigns, analyze wasted spend, create Search structure safely, and manage keywords — with explicit approval for anything that changes an ad account.

## What AdCue is for

| Goal | How AdCue helps |
|------|-----------------|
| Understand account state | List campaigns, structure, performance, and connection health |
| Find waste | Search-term analysis, wasted-spend signals, budget recommendations |
| Create safely | New Search campaigns and ads land **PAUSED** by default |
| Operate from AI tools | MCP tools for Claude, Cursor, ChatGPT, and similar clients |

## Platforms today

AdCue’s live surface is **Google Ads**.

Meta, TikTok, Amazon, LinkedIn, and other platforms are **not** available as documented product features. Do not expect how-to pages or tool names for those platforms in this site.
