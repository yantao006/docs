# Usage & Billing

The authenticated home at [adcue.app/app](https://adcue.app/app) shows the current subscription, tool-call usage, connection health, and available plans.

## Billing vendor

AdCue uses **Creem** for checkout, the customer portal, and subscription lifecycle webhooks.
AdCue does not use Stripe Checkout or Stripe Customer Portal.

## Available plans

| Plan | Price | Tool calls | Trial |
|------|-------|------------|-------|
| Pro | $79/month | 500/month | 7 days |
| Business | $249/month | 2,000/month | 7 days |
| Enterprise | $799/month | 10,000/month | 7 days |

See the complete matrix on [Pricing](/knowledge/pricing).

## What you can do

| Action | Entry |
|--------|-------|
| See current plan and status | Current Plan card |
| See live tool-call usage | Tool Calls card |
| Start a 7-day trial | Available Plans cards |
| Switch plans | Available Plans cards |
| Manage payment or cancellation | Creem customer portal entry |

Users without an active plan have zero tool-call quota.
The app shows a trial prompt instead of a Free plan.

If billing environment variables or the requested product ID are missing, checkout fails closed.
The UI does not claim that trial access started until Creem checkout and webhook processing succeed.
