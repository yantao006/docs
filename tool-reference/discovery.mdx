# Discovery and accounts

These tools help you discover capabilities, inspect connections, and route Google Ads actions.

Key tools: `search_tools`, `get_tool_schema`, `list_connected_accounts`, `get_connections_status`, `get_usage_status`, `google_ads`.

See the [tool catalog](/mcp/tools) for the full list and [Tool Reference overview](/tool-reference/overview).
